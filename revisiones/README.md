# Revisiones

Todas las revisiones son **adversariales entre modelos de IA** (sobre todo ChatGPT, más una revisión de código con Gemini), no revisiones humanas independientes. Se conservan para que cualquier revisor humano vea qué se discutió, qué se aceptó y qué se rechazó. Las rondas no son independientes entre sí: el revisor principal es el mismo.
